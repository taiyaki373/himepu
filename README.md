# 姫ぷオンライン

姫を守りながら生き残る、2〜5人向けオンライン協力ゲームの初期プロトタイプです。

## 起動

Node.js 20以降で、依存パッケージを追加せずに起動できます。

```sh
npm start
```

ブラウザで `http://localhost:3000` を開き、「ルームを作成」を押すと6文字の部屋コードが発行されます。そのコードを共有し、参加者はコードを入力して合流します。Codespacesなどで複数人が遊ぶ場合は、ポート3000を公開してください。部屋を作ったプレイヤーがホストになり、2人以上で「ゲーム開始」を押すと始まります。

## 操作

- `W`, `A`, `S`, `D`: 移動
- 姫はマップ中央に固定され、マウス照準＋クリック（スマートフォンでは照準スティック）で攻撃します。`Q`または画面内のボタンでナイト全員にバフをかけます。
- ナイトは選んだ武器で自動攻撃し、`W`, `A`, `S`, `D`またはスマートフォンのスティックで移動します。画面は固定で、マップ全体を表示します。

ナイトは敵のHPを1で止め、姫の攻撃で敵を倒せます。敵が落とす経験値は近づいたプレイヤーが拾います。ナイトが拾うと取得量の50%が姫にも入り、ナイトは攻撃力・攻撃速度・移動速度、姫はナイトの経験値取得量・攻撃力・姫バフの効果時間から強化を選べます。全5ウェーブで敵の種類と強さが上がり、最後にボスが出現します。姫が倒れる、または最後のウェーブの制限時間内にボスを倒せないと敗北します。ウェーブ時間や強化値などは初期調整用です。

## 現在の範囲

ルーム作成とコード参加、最大5人、姫1人と武器を選べるナイト、全5ウェーブ、遠距離敵とナイトの攻撃を封じる敵、ボス戦、経験値共有と役割別の3種のレベル強化、姫のバフを実装しています。経験値共有率などの数値は初期調整用です。アカウント、再接続、永続データ、チャット、複数ルームの永続化はありません。ルームとゲーム状態はサーバープロセス内で管理されます。
